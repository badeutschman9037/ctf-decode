# Security Policy

## Supported versions

Only the latest release of ctf-decode receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability
reporting: go to the **Security** tab of this repository and click
**Report a vulnerability**.

Include a description of the issue, steps to reproduce it, and the version
affected. You can expect an initial response within 14 days. Once a fix is
ready, it will be released and the reporter credited (unless they prefer
otherwise).
