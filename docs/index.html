ctf-decode

Decode the encodings you hit in every CTF, in one command.

$ ctf-decode auto "ZmxhZ3toZWxsb30="
[base64] flag{hello}

Decoders

base64
Padding optional
hex
Spaces, colons, 0x prefix
binary
8-bit groups to text
url
Percent-encoding
rot / rotall
Caesar, or brute-force all 25
auto
Tries everything at once

Install

git clone https://github.com/badeutschman9037/ctf-decode.git
cd ctf-decode
pip install .
